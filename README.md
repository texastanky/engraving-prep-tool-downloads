# engraving-prep-tool-downloads

Public installer downloads for Engraving Prep Tool.

## Color Vectorizer

Downloads live on the [Releases page](https://github.com/texastanky/engraving-prep-tool-downloads/releases).
Each release carries `color-vectorizer-beta.zip` and `SHA256SUMS.txt`; verify with
`sha256sum -c SHA256SUMS.txt` after downloading both. The release list is the only
way to get a build — there are no build folders in the tree.

| Release | Notes |
| --- | --- |
| cv-v0.1.0-beta.4 | Colour picker: layer colours come from measured swatches. Library ships empty until a plate readsheet is imported. |
| cv-v0.1.0-beta.2 | Recipes inside the measured window, caveat on every settings sheet. |
| cv-v0.1.0-beta.1 | First public beta. |
